今天给所有开发者推荐一款GitHub 8.7k+ Star的硬核开源工具——9Router。

它是专为AI编程场景打造的本地智能路由网关，让你实现：订阅优先、廉价兜底、免费保活、永不中断、自动省Token。

一、核心定位：AI编程的“智能调度中枢”

 

9Router 是一个本地中间层代理，作用：

 

- 统一接入 40+ AI厂商、100+大模型

- 对接 Claude Code、Codex、Cursor、Cline、Copilot 等主流AI编程工具

- 提供自动路由、负载均衡、降级容错、Token压缩、可视化监控

- 对上层客户端完全透明，无侵入、无感知

 

一句话总结：

以后你的AI编辑器只连 9Router，谁提供算力、怎么切换，完全不用管。

 

二、核心技术能力（工程师必看）

 

1. 三层智能降级路由（核心）

 

系统内置高可用调度策略，按优先级自动切换，保证任务永不中断：

 

1. 付费订阅层（优先）

用尽你已付费的 Claude Code、Codex 等官方订阅额度

2. 廉价API层（补给）

自动切到 GLM、MiniMax、DeepSeek 等高性价比模型

3. 免费额度层（兜底）

Kiro AI、Vertex AI 等免费渠道，确保不断连

 

2机制：配额耗尽 → 自动切换 → 无感知续跑 → 不打断编码流程

 

2. 内置 RTK Token 压缩引擎（省40%）

 

集成 Rust 编写的 RTK  Token优化器，自动：

 

- 清理 git diff 冗余重复行

- 过滤日志噪音、无关栈信息

- 精简目录层级、压缩上下文

- 平均减少 20%~40% 输入Token

 

优势：不用额外装插件，默认开启，持久省钱。

 

3. 全平台兼容，几乎支持所有AI编程工具

 

- Claude Code

- GitHub Copilot

- Cursor

- Cline

- Codex

- Antigravity

- 其他兼容 OpenAI 规范的客户端

 

接入标准：兼容 OpenAI v1 接口，替换地址即可用。

 

4. 灵活接入方式（两种都支持）

 

- OAuth登录：直接绑定 Claude/Copilot 订阅账号

- API Key接入：填入 OpenAI、Anthropic、GLM 等40+厂商密钥

- 支持混合管理：订阅 + API + 免费渠道一起用

 

5. 可视化仪表盘（本地Web面板）

 

访问：http://localhost:20128

可实时查看：

 

- 各渠道Token消耗与额度

- 实时路由切换日志

- 成本统计与趋势

- 模型可用性监控

 

6. 高可用特性

 

- 自动重试

- 失败自动降级

- 多厂商负载均衡

- 本地部署，数据不上云

 

 

三、安装与部署（一行命令）

 

1. 安装

npm install -g 9router

 

2. 启动

9router

 

3. 访问面板

 

http://localhost:20128

 

4. 接入AI编程客户端（以 Claude Code 为例）

 

编辑配置文件：

 ~/.claude/config.json 

 

写入：

 

json
  

{

  "anthropic_api_base": "http://localhost:20128/v1",

  "anthropic_api_key": "你在9Router面板生成的API Key"

}

 

 

重启客户端即可完成接入。

 

其他工具（Cursor/Copilot）只需把 API Base 设为：

 http://localhost:20128/v1 

 

四、9Router 解决的真实痛点

 

1. 额度用尽被打断 → 自动切廉价/免费模型

2. 多账号多密钥混乱 → 统一面板管理

3. Token消耗过快 → RTK自动压缩省40%

4. 付费模型太贵 → 免费/低价兜底，大幅降本

5. 切换模型麻烦 → 全自动路由，无需手动改配置

- 同时使用多个AI助手的重度用户

- 希望降本、不想被订阅绑架的人

- 追求稳定、不希望任务中断的人

- 想统一管理多厂商模型的技术团队
