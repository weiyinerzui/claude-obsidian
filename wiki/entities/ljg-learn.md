# ljg-learn

A creator and open-source developer who transitioned from a humanities background (journalism, marketing) into prolific "vibe coding." Known for building and shipping multiple projects that collectively accumulated over 30,000 GitHub stars, despite never having formally studied computer science.

## Background

- Studied humanities; never took a CS course
- Published a viral 2023 blog post "Why I'm Not Learning to Code," arguing that tech needs more humanities perspectives
- Started vibe coding in early 2025; January 2025 marked the turning point when AI coding agents became capable enough to ship end-to-end products

## Key Projects

| Project | Description | Stars |
|---------|-------------|-------|
| Front-End Slides | HTML-based presentation skill replacing PowerPoint; uses Design MD tokens | 21,000+ |
| Tab Out | Chrome extension that makes closing tabs addictive via gamification | Open source |
| YouTube Learning Tool | Interactive video companion with transcripts, chapter navigation, and note-taking | In development |
| Codebase to Course | Auto-generates interactive CS courses from GitHub repos | Open source |
| X Bookmark Injector | Chrome extension that inserts saved bookmarks into the X homepage feed | Personal tool |

## Philosophy

- Treats AI coding agents as **co-founders**, not employees
- Describes **problems**, not solutions, when prompting
- Believes coding is evolving from a profession into a **general skill**, like writing
- Advocates for **opinionated products** over generic AI tools
- Follows a **build to learn** approach: build first with AI, then understand how it works
- GitHub as a medium for self-expression, analogous to Substack for writers
