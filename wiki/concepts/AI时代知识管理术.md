# AI时代知识管理术

知识/记忆管理系统的终极目标：尽可能完整地记录、便捷地搜索、高效地分析、清晰地组织、尽可能自动化。在植入式记忆增强装置问世之前，一切手段都是现时代技术条件下的妥协产物。

## 四阶段模型

### 1. 记录：顺手且集中，跟着感觉走

- "客厅的知识管理"（形式感优先）vs "厨房的知识管理"（顺手感优先）——后者才是正确方向
- 记录时不做精细加工与分类，加工和记录分离
- "集中"比"有序"重要得多——能在同一平台搜索远比分门别类关键
- 知识管理软件不超过三个：大体量内容（Notion/Zotero）、零碎内容（Flomo）、汇总组织（第二大脑）
- 记录线索：**启发感**——PP理论视角下，启发感来自大脑预测失败，前扣带皮层提醒"你可能错了"

### 2. 检索：将自己接入世界，搜索搜索再搜索

- 检索的本质也是对经验的双重编码，目的是将个体经验外化以寻求关联
- 记录时出发点是"我有启示/答案"，搜索时出发点是"我有困惑/问题"
- 搜索技能差异造成认知鸿沟：科学上网、filetype:、AI辅助论文筛选
- Research的本质就是再次搜索、重新搜索

### 3. 分析：管理问题，而不是管理答案

- 一切知识都是某种"答案"，答案怎么答取决于问题怎么问
- 可以没有知识库，但最好有问题库
- 两个方向：论文拆解Prompt（大→小）和概念阐释Prompt（小→大）
- 论文拆解7要素：标题-背景与冲突-关键问题-关键结论-论证过程-类比解释-实际意义
- 概念阐释5维度：概念（what/how/why）-关系-过去-现在-未来

### 4. 组织：死去的记忆正在第二大脑中攻击你

- 知识管理工具的核心功能是**联想**：关联推荐 + 创造回忆
- Obsidian + Smart Connections + OpenAI API = 语义联想的第二大脑
- 知识管理的极简原则：找到一个有语义联想功能的容器，把所有内容收集进去

## 知识管理焦虑

- 知识焦虑是害怕自己不知道，知识管理焦虑是知道了又害怕记不住
- "忘了就忘了，说明它们不重要"——深挖一个主题时天然有对材料的敏感
- 深度创作本身就是最好的知识管理活动
- 重要的是知识组块彼此关联，而且你亲自创造了这种关联
