# 高手的黑箱共读大纲

## 总主线

一句话总纲：

```text
这套课讲的是：
AI时代，人的认知能力如何从“记住知识”
一路发展到“创造作品”。
```

整体链条：

```text
记忆
  -> 理解
  -> 应用
  -> 分析
  -> 评价
  -> 创作
```

也可以理解成：

```text
存住材料
  -> 看懂结构
  -> 带入现实
  -> 生产解释
  -> 作出判断
  -> 凝成作品
```

---

## 第 2 讲：记忆

核心问题：

```text
知识如何被留下来？
```

主线：

```text
记忆常识
  -> 记忆新知
  -> 记忆原则
  -> AI时代知识管理
```

关键主题：

```text
工作记忆 vs 长时记忆
外显记忆 vs 内隐记忆
注意力与工作记忆
最小记忆策略
预测处理理论
记忆的辩证法
意外、回溯、具体
AI时代知识管理术
```

一句话：

```text
记忆不是为了保存过去，而是为了预测未来。好的知识管理不是囤积材料，而是让材料在未来能重新发生意义。
```

```text
  -> 概念地图

```

关键主题：

```text
深度理解
认知负荷理论
元素交互性
分割策略
交替实例
概念地图
抽象思维
知识、体验、模型、现象的匹配
```

```text
理解不是记住概念，而是让知识、体验、模型和现象匹配起来，看见复杂关系中的意义。
```

## 第 4 讲：应用

核心问题：

```text
知识如何进入现实？
```

主线：

```text
知识落地的两条进路
  -> 结构化知识与AI
  -> 菜谱型知识与硬技能
  -> 知行显隐四象限
  -> 元认知知识作为提示词
  -> 穿透差异
  -> 与高手心智对齐
```

关键主题：

```text
知识应用
结构化知识
菜谱型知识
知行显隐四象限
元认知知识
WOOP模型
GROW模型
对比反馈练习
```

一句话：

```text
应用不是懂了一个道理，而是让知识进入具体任务、变量、工具、步骤和反馈，真正改变行动。
```

## 第 7 讲：创作

核心问题：

```text
人如何把认知能力凝结成作品？
```

主线：

```text
回顾前六讲
  -> AI辅助人机共创工作流
  -> AI与人的共创哲学
  -> 个人创作者商业化
  -> 结课作业
```

关键主题：

```text
创作能力
人的事物化
创作模式
深度创作
涟漪性与绵延性
人机共创工作流
黑箱化工作流
智能体工作流
认知成长微笑曲线
生活-创作-商业模式
```

一句话：

```text
创作是把记忆、理解、应用、分析和评价统合为作品。AI加速中段流程，但人的问题、品味、差异和生活结构仍是核心。
```
