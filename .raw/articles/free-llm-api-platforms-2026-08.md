## 四、进阶指南：如何用 9router 统一管理

> **适合有一定编程基础的或者有兴趣研究的小伙伴儿操作。**
> 
> 



由于各个平台的 API 格式、Key 各不相同，手动切换非常麻烦。9router 是目前最流行的开源大模型接口管理系统，可以将杂乱的 API 整合为一个标准的 OpenAI 格式接口。

### 项目简介

使用 RTK \+ 自动切换到免费/低价 AI 模型，节省 20\-40% 的 tokens。

将所有 AI 编程工具（Claude Code、Cursor、Antigravity、Copilot、Codex、Gemini、OpenCode、Cline、OpenClaw\.\.\.）连接到 40\+ AI 提供商和 100\+ 模型。

搬运的项目地址：

https://gitee\.com/weiyinerzui/9router



### 主要功能及优点：

- ✅ RTK Token 节省器 \- 自动压缩 tool\_result 内容，每次请求节省 20\-40% tokens

- ✅ 充分利用订阅 \- 追踪配额，在重置前用尽每一分额度

- ✅ 自动切换 \- 订阅 → 低价 → 免费，零停机时间

- ✅ 多账户支持 \- 按提供商在账户之间轮询

- ✅ 通用兼容 \- 支持 Claude Code、Codex、Cursor、Cline 以及任何 CLI 工具

#### 进阶功能：添加模型组合

添加模型组合，可以组合多个不同提供商的模型进行组合使用，可以为每个组合选择策略：

- 回退— 按顺序尝试模型（失败时切换到下一个）

- 轮询— 在请求间轮换模型以分散负载

- 融合— 并行查询所有模型，然后由裁判综合出一个答案。质量最佳但成本最高：每次请求会计费所有面板模型 \+ 裁判（N\+1 次调用）

- 容量自动切换— 将图片/PDF/音频请求优先发送到支持的模型

![image\.png](https://img.xxn521.dpdns.org/%7Byear%7D/%7Bmonth%7D/%7Bhash%7D/image%205.webp)
